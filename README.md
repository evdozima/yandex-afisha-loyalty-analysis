# Yandex Afisha — Loyalty Analysis

## О проекте
Проект посвящён анализу лояльности пользователей Яндекс Афиши на основе данных о заказах и активности пользователей.

## Цель
Исследовать поведение пользователей и выявить показатели, которые помогают оценить лояльность и удержание аудитории.

## Этапы работы
1. Подключение к базе данных и получение данных с помощью SQL.
2. Загрузка данных и первичная проверка качества.
3. Очистка и подготовка данных к анализу.
4. Исследование пользовательской активности и показателей лояльности.
5. Визуализация результатов.
6. Формулирование выводов и рекомендаций.

## Инструменты
* Python
* Pandas
* SQL
* Jupyter Notebook
* Matplotlib / Seaborn (если используются в проекте)
